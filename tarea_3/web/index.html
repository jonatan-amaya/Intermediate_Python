Metodología, fuentes y limitaciones

Metodología

Se descargaron las series anuales 2000–2024 de tres indicadores del Banco Mundial —pobreza monetaria (línea nacional, % de población), índice de Gini y PBI per cápita— para 18 países de América Latina y el Caribe. Los datos se depuraron (se eliminaron duplicados y valores faltantes se dejaron explícitos como nulos), se pivotearon a matrices país × año y se calcularon KPIs y variaciones en puntos porcentuales. Pipeline reproducible en scripts/obtener_datos.py, procesar_datos.py y analizar_datos.py.

Fuentes

Banco Mundial, API pública de indicadores de desarrollo (consultada el 2026-11-01): SI.POV.NAHC, SI.POV.GINI, NY.GDP.PCAP.CD. Para Perú, la serie de pobreza coincide con las cifras oficiales del INEI (línea nacional).

Limitaciones

  • La pobreza con línea nacional no es estrictamente comparable entre países (cada uno define su umbral); sí lo es la evolución dentro de cada país y el ranking aproximado.
  • Brasil no reporta pobreza con línea nacional al Banco Mundial (sí Gini y PBI); se excluye de los rankings de pobreza (17 países con datos).
  • El Gini tiene años faltantes en algunos países; el ranking usa el último año disponible común (2024) con cobertura parcial (14 países).
  • Los datos 2024 pueden estar sujetos a revisión por el productor oficial.
